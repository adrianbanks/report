There are 28 use cases in total. These can be split up into four main areas depending upon their use :


Hotel Use Cases

These relate to the main functions of the hotel associated with rooms.


Restaurant Use Cases

These relate to the functions of the restaurant associated with tables.


Manager Use Cases

These relate to the administrative functions associated with the running of the hotel.


Maintenance Use Cases

These relate to the functions associated with the general upkeep of the hotel.
