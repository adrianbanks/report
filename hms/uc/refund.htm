Use Case : Refund An Item To A Guest

 
Actor Action
 
System Response
1 Manager/restaurant manager enters the guest's customer number (from the guest's receipt of payment slip). 2 Check that the guest's customer number is a valid customer number.
    3 Display the guest's details.
4 Manager/restaurant manager enters the amount to be refunded. 5 Print out a receipt of the refund. Log the refund.

Alternate Cases :

  • (2) If the customer number is not a valid customer number, alert the user.
