Use Case : Guest Cancels A Room Booking

 
Actor Action
 
System Response
1 Guest approaches the reception desk or telephones and requests to cancel a booking.    
2 Receptionist enters the customer's booking number. 3 Check for a valid booking number and that the booking has not already been used. Log that the booking has been cancelled.
4 Customer leaves the reception desk, or hangs up the telephone.    

Alternate Cases :

  • (3) If the booking number is not a valid booking number, alert the user and exit from the cancel booking function.
