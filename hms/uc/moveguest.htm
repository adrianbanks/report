Use Case : Move Guest To Another Room

 
Actor Action
 
System Response
1 Manager enters the guest's customer number. 2 Check the customer number is a valid customer number.
    3 Display the guest's details.
4 Manager enters the new room number of the guest. 5 Check the room number entered corresponds to a vacant room. Log that the guest is in a different room.

Alternate Cases :

  • (2) If the customer number is not a valid customer number, alert the user.
  • (5) If the new room number corresponds to a room which is not vacant, alert the user.
